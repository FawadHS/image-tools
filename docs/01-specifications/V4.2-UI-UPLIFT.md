# Version 4.2 UI Uplift - IA + Layout Proposal

Date: 2026-02-05
Status: Draft (Sprint 1 - IA + Layout)

## Goals
- Keep current visual style while improving clarity, scanability, and mobile usability.
- Preserve existing workflows and central render pipeline.
- Make the primary flow obvious: Upload -> Configure -> Convert -> Download.

## Current Layout (Baseline)
- Two-column grid on desktop.
  - Left: DropZone, FileList, ActionBar, History, Reviews.
  - Right (sticky): ImageEditor, CropTool, TextOverlayTool, SettingsPanel, ExifPanel, ShopifyPanel.
- On mobile, all modules stack in a long scroll with weak action emphasis.

## Proposed Layout (Desktop)

### Structure
- 12-column grid with a clear primary column and focused secondary panel.

#### Primary Column (8 cols)
1) Upload + Queue
   - DropZone (top)
   - FileList (primary focus for batch operations)
   - ActionBar (Convert/Download) anchored below FileList
2) Preview + Quick Edits (collapsed by default)
   - Inline Preview card
   - Quick actions (Rotate, Flip, Crop, Text) as compact buttons
   - Expands into full editor only when needed
3) History (collapsed by default)

#### Secondary Column (4 cols) - “Settings Stack” (sticky)
A) Conversion Settings
B) AI Enhancements
C) EXIF (collapsed)
D) Shopify (collapsed)

### Key UI Changes (No feature changes)
- Add a “Quick Edit” row above FileList to jump into editor mode.
- Move ImageEditor/Crop/TextOverlay into a single “Editor Drawer” section
  - Collapsible panel with tabs: Adjust, Crop, Text.
  - Default collapsed to reduce vertical scroll.
- Group SettingsPanel sections into labeled groups with accordion behavior:
  - Output + Quality
  - Resize + Metadata
  - Naming
  - AI Enhancements
- ActionBar becomes a primary sticky element on desktop within the left column (not global).

## Proposed Layout (Mobile)

### Structure
- Single column with a top sticky action bar.

Order:
1) Upload
2) File queue (compact list)
3) Primary action bar (sticky bottom)
4) “Edit” collapsible drawer
5) “Settings” collapsible drawer
6) “Advanced” drawer (AI/EXIF/Shopify)

### Mobile Behaviors
- Sticky bottom action bar: Convert / Download / Cancel.
- File list items become condensed rows (preview + status + size delta).
- Editor tools become full-width drawers with a clear “Done” button.

## IA Restructure (Component Mapping)

| Current Component | New Placement | Notes |
|------------------|---------------|-------|
| DropZone | Primary column, top | Unchanged
| FileList | Primary column | Add compact mode for mobile
| ActionBar | Primary column (sticky in mobile) | Always visible
| ImageEditor | Editor Drawer | Tabbed inside a single panel
| CropTool | Editor Drawer | Tab
| TextOverlayTool | Editor Drawer | Tab
| SettingsPanel | Settings Stack | Grouped sections + accordion
| ExifPanel | Advanced (collapsed) | Keep lazy loaded
| ShopifyPanel | Advanced (collapsed) | Keep lazy loaded
| HistoryPanel | Collapsed in primary column | Collapsible

## Information Hierarchy
1) File queue + action button
2) Preview + quick edits
3) Settings + AI
4) Advanced integrations

## Risks & Mitigations
- Risk: Users missing advanced options if too collapsed.
  - Mitigation: Use short “peek” summaries under collapsed sections.
- Risk: Editor drawer complexity.
  - Mitigation: Keep tabs minimal and reuse existing components.

## Deliverables (Sprint 1)
- Wireframe-level layout restructure plan.
- Component mapping and grouping (done in this doc).
- Validate with one desktop + one mobile mock layout.

## Out of Scope (Sprint 1)
- Visual redesign / color changes.
- New features.
- Any conversion pipeline changes.
